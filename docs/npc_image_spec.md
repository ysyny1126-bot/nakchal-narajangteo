# NPC 이미지 사양서

사무실에 서 있는 사람 NPC(지금은 단순 도형)를 직접 그린 이미지로 바꾸기 위한 요청서입니다.
이미지는 3D 공간에 세워지는 판(빌보드)으로 들어가며, 항상 카메라를 향합니다.

| `lead_han.png` | 한 과장 | EP2 쇼핑몰운영과 | 30대 후반, 청록 재킷, 주황 포인트, 빠릿빠릿 |

## 형식

- **PNG, 배경 투명**
- **세로 1024px 안팎** (가로는 자유). 6장 모두 같은 크기 기준으로 그려 주세요.
- **전신, 정면 또는 살짝 비스듬한 정면**. 발끝이 이미지 맨 아래에 닿게(여백 0~10px).
- 머리 위 여백은 조금만. 이름표는 게임에서 따로 띄우니 그림에 글자는 넣지 않아도 됩니다.
- 그림체는 나라미·달이(부드러운 3D 렌더, 2~2.5등신)와 맞추면 가장 자연스러워요.
- 키 비율: 어른 NPC는 나라미보다 머리 반 개 정도 크게.

## 있으면 좋은 것 (선택)

- 인물마다 **말하는 표정 1장 더** (`lead_park_talk.png`처럼 `_talk`를 붙여서). 대화할 때 바꿔 끼웁니다.
- 출처가 직접 제작 또는 CC0인지 한 줄 메모.
